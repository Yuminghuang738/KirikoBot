# 项目图标规格（给 Ren 用 Pillow 生成）

目标：`assets/icon.png`，512×512 RGBA，粉色樱花 + 简单 K 标记，README 顶部 136px 引用。

## 画布

- 512×512，RGBA；不透明背景（GitHub 亮/暗主题下都稳）。
- 圆角方形：外接矩形 32,32 → 480,480，圆角半径 **96px**；圆角外透明。
- 背景：左上 `#FFD9E8` → 右下 `#FF9EC4` 斜向线性渐变；左上再加一层低透明度白色径向柔光（中心 25% 处，半径 60%，alpha 35），让画面不闷。

## 中央 K

- 纯白 `#FFFFFF`，几何圆角笔画，整体高度约 **280px**（画布 55%），宽度约 210px，居中略偏左（视觉重心）。
- 笔画宽 **56px**，端点/转角用圆角（Pillow 用多边形 + 圆端近似，或画粗线后用圆盖）。
- 外描边：深玫瑰 `#7A3352`，宽 **6px**，保证 64px 下仍有轮廓；再向外一层 8px、alpha 25 的阴影（偏移 0,6，模糊 12）。
- K 的右上斜臂可以稍微短一点，给樱花让位；不要做复杂花体，64px 下必须一眼认出 K。

## 樱花

- 右上角一朵五瓣樱花：中心约 (392,118)，整体半径 **58px**；花瓣 `#FFF0F6`，边缘 `#FFB7D5` 1.5px，花心 `#FFD1E3` 小圆点。
- 右下/左下飘 2–3 片单瓣：alpha 分别 0.55 / 0.35 / 0.25，大小 18–26px，方向错开。
- 不要用任何角色立绘、游戏截图或版权素材；只保留抽象花瓣 + K。

## 输出与验收

- 只输出 `assets/icon.png`（512×512，PNG）。
- 缩到 64×64 看一眼：K 仍清晰、樱花不糊、圆角干净。
- README 顶部 `<img src="assets/icon.png" width="136" height="136" alt="KirikoBot 图标">`。
- 建议同时保留生成脚本 `scripts/gen_icon.py`（Pillow，可复现），但 CI/运行不依赖它。
